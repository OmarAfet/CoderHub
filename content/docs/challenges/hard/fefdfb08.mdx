## الوصف

قم بكتابة دالة `function` تستقبل عدد من نوع `integer` و تقوم بإرجاع الارقام في `Tribonacci Sequence` بعدد هذا الرقم ، **Tribonacci Sequence هي شبيهة للـ Fibonacci Sequence لكنها تجمع اخر ٣ ارقام**

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `num = 5` | `[1,1,1,3,5]` |
| `num = 6` | `[1,1,1,3,5,9]` |
| `num = 2` | `[1,1]` |
| `num = 9` | `[1,1,1,3,5,9,17,31,57]` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/fefdfb08-8157-4dfb-b467-3f924b11e42b/view)

## الحل

```python tab="Python"
def tribonacci(num):
    if num == 0:
        return []
    elif num == 1:
        return [1]
    elif num == 2:
        return [1, 1]
    elif num == 3:
        return [1, 1, 1]
    else:
        t = tribonacci(num - 1)
        next_num = t[-1] + t[-2] + t[-3]
        t.append(next_num)
        return t
```
