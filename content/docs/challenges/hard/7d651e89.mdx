## الوصف

مع اقتراب عام 2030، تستعد المملكة لاستضافة فعاليات عالمية ضخمة، وأحد أكبر الأحداث هو افتتاح كأس العالم.
المدن تتزين، الشوارع تمتلئ بالأعلام، والملاعب تُجهّز لاستقبال مئات الآلاف من المشجعين.
أمامك قائمة بالملاعب الجاهزة، كل واحد منها بسعة جماهيرية معينة.

اليوم، مطلوب منك اتخاذ قرار استراتيجي: ما هو أقل عدد من الملاعب يجب فتحها وتشغيلها للوصول إلى السعة المستهدفة في يوم الافتتاح؟
الأمر ليس سهلاً، فالوقت والموارد محدودة، ويجب أن تختار بعناية أكبر الملاعب أولًا لتصل للهدف بأقل عدد ممكن.
أما إذا كان الهدف صفرًا، فالجواب واضح: صفر ملاعب. وإن كان مجموع سعاتك كلها لا يكفي للوصول للهدف، فعليك أن تكون صريحًا وتعيد النتيجة -1.

**المثال الإرشادي**:
إذا كانت السعات `[40000, 30000, 20000]` والهدف `70000`:

- ابدأ بالأكبر (40000) → المجموع 40000 (ملعب واحد)

- ثم 30000 → المجموع 70000 (ملعبان)
بهذا، ضمنت استقبال كل الجماهير بأقل جهد.

```python tab="Python"
from typing import List
def minStadiumsForCapacity(capacities: List[int], targetCapacity: int) -> int:
    if targetCapacity == 0:
        return 0
    if sum(capacities) < targetCapacity:
        return -1
    capacities.sort(reverse=True)
    total = 0
    for i, c in enumerate(capacities):
        total += c
        if total >= targetCapacity:
            return i + 1
    return -1
```
