## الوصف

في غرفة العمليات الزرقاء، تصلنا إشارات إنذار من مصدرين مختلفين (مستشعرين في شبكتين منفصلتين). كل مستشعر يعطي طوابع زمنية (بالثواني) للحوادث المرصودة. المشكلة: التأخير في الشبكة قد يجعل نفس الحادث يظهر بطابعين مختلفين بين القائمتين، لكن الفارق يكون صغيرًا.

مهمّتك هي **دمج** القائمتين في مخطط زمني واحد **مع إزالة التكرار** وفق قاعدة واضحة:

- نعتبر الطابعين يعبّران عن **نفس الحدث** إذا كان الفرق بين **الطابع اللاحق ومُمثّل المجموعة** ≤ `tolerance` (لاحظ: المعيار دائمًا مع **ممثل المجموعة** وليس مع أي عنصر آخر لتجنّب التسلسل/السلسلة).

- نختار **أصغر طابع** في المجموعة كمُمثّل لها.

- النتيجة تكون قائمة الطوابع الممثلة، **مرتّبة تصاعديًا**.

**مثال توضيحي:**
`A = [10,12]` ، `B = [13,14]` ، `tolerance = 3`
بعد الدمج والفرز: `[10,12,13,14]`

- نبدأ مجموعة بممثل = `10`.

- `12 - 10 = 2 ≤ 3` ⇒ ضمن نفس المجموعة.

- `13 - 10 = 3 ≤ 3` ⇒ ضمن نفس المجموعة.

- `14 - 10 = 4 > 3` ⇒ نبدأ مجموعة جديدة بممثل = `14`.
**الناتج:** `[10,14]`.

ملاحظة مهمّة: **لا** نسمح بتأثير السلسلة (chaining). أي لا نقارن 14 مع 12، بل دائمًا مع ممثل المجموعة (الأول فيها).

```python tab="Python"
from typing import List
def mergeShadowSignals(streamA: List[int], streamB: List[int], tolerance: int) -> List[int]:
    merged_stream = sorted(streamA + streamB)

    if not merged_stream:
        return []

    if tolerance <= 0:
        return merged_stream

    actor = merged_stream[0]
    r = [actor]

    for m in merged_stream[1:]:
        if m - actor > tolerance:
            actor = m
            r.append(m)

    return r
```
