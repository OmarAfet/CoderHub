## الوصف

في يوم التأسيس السعودي، قرر **ناصر** و**فهد** و**سعد** القيام برحلة عبر **مناطق المملكة المختلفة** لاكتشاف طرق الاحتفال بهذه المناسبة الوطنية العزيزة. أرادوا أن يتعلموا **كيف يحتفل أهل كل مدينة** بيوم التأسيس، وما هي **التقاليد والأكلات واللباس** التي تميز كل منطقة.

لكن قبل أن يبدأوا رحلتهم، فكر **ناصر** وقال:
*"بدلاً من أن نتجول بلا خطة، لماذا لا نصمم برنامجًا بسيطًا يخبرنا عن عادات كل مدينة؟"*

وافقه **فهد** بحماس وقال:
*"فكرة رائعة! كل ما علينا فعله هو إدخال اسم المدينة، وسيعطينا البرنامج كل التفاصيل التي نحتاجها!"*

### **🚀 التجربة الأولى: الرياض – قلب المملكة النابض**

📌 **سعد يبدأ رحلتهم ويسأل البرنامج عن الرياض**

`console.log(get_foundation_day_celebration("الرياض"));`🔍 النتيجة:

"الرياض: العرضة النجدية - المشلح والغترة - القرصان"

✨ **التفسير:**
في **الرياض**، الاحتفال يكون بـ **العرضة النجدية**، حيث يصطف الرجال حاملين السيوف ويرددون الأبيات. **يرتدون المشلح والغترة**، وتُقدم أكلة **القرصان** كطبق شهير في هذه المناسبة.

### **🚀 التجربة الثالثة: الحدود الشمالية – تراث الصحراء**

📌 **فهد يسأل عن احتفالات أهل الشمال**

`console.log(get_foundation_day_celebration("الحدود الشمالية"));`🔍 النتيجة:

"الحدود الشمالية: الدحة - البشت والعقال والثوب المرودن - المليحية"

✨ **التفسير:**
في **الحدود الشمالية**، تتميز الاحتفالات بـ **لعبة الدحة**، حيث يجتمع الرجال في صفوف متراصة ويرددون الأبيات بصوت قوي يشبه زئير الاسود و هدير الجمال ، تعبيرًا عن القوة والوحدة. اللباس التقليدي يتكون من **البشت والعقال والثوب المرودن**، أما الأكلة المشهورة فهي **المليحية**، وهي وجبة دسمة يتم تقديمها في هذه المناسبات.

from typing import List

def get_foundation_day_celebration(city: str) -> str:
    city = city.strip()
    if city == "الرياض": return "الرياض: العرضة النجدية - المشلح والغترة - القرصان"
    if city == "جدة": return "جدة: الزفة الحجازية - الثوب الحجازي والشماغ - المعصوب"
    if city == "الدمام": return "الدمام: الفجري - الثوب والدقلة - المرقوق"
    if city == "أبها": return "أبها: الخطوة الجنوبية - الثوب الجنوبي - الحنيذ"
    if city == "الحدود الشمالية": return "الحدود الشمالية: الدحة - البشت والعقال والثوب المرودن - المليحية"
    if city == "حائل": return "حائل: سامري حائل - البشت والعقال - كبيبة حائل"
    return "معلومات غير متوفرة لهذه المدينة"
