## الوصف

قم بكتابة دالة `function` تستقبل قيمة نصية من نوع `string` ، تقوم الدالة **بفصل الكلمات** **عند ملاحظة حرف كبير بوضع مسافه وتحويله لحرف صغير**، ثم قم بارجاع النتيجة من نوع `string`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `txt = "wePlayTennis"` | `"we play tennis"` |
| `txt = "iLikeCats"` | `"i like cats"` |
| `txt = "computerScience"` | `"computer science"` |
| `txt = "thankYou"` | `"thank you"` |

## الحل

```python tab="Python"
def cap_space(txt: str) -> str:
    result = ''
    for i, c in enumerate(txt):
        if c.isupper() and i > 0:
            result += ' '
        result += c.lower()
    return result
```
