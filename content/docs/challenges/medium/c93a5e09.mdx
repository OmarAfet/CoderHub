## الوصف

قم بكتابة دالة `function` تستقبل قيمة نصية `string` تُمثل تاريخ اليوم، تقوم الدالة بإرجاع تاريخ اليوم **بثلاث تنسيقات مختلفة**.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `date = "2020/1/1"` | `"2020/1/1 \| 2020-1-1 \| 1/1/2020"` |
| `date = "2019/12/28"` | `"2019/12/28 \| 2019-12-28 \| 12/28/2019"` |
| `date = "2010/10/30"` | `"2010/10/30 \| 2010-10-30 \| 10/30/2010"` |
| `date = "2013/11/29"` | `"2013/11/29 \| 2013-11-29 \| 11/29/2013"` |

## الحل

```python tab="Python"
def date_format(date: str) -> str:
    x = date.split('/')
    split1 = x[0]
    split2 = x[1]
    split3 = x[2]
    reverse = f'{split2}/{split3}/{split1}'
    dash = '-'.join(x)
    x = f'{date} | {dash} | {reverse}'
    return x
```

```js tab="JavaScript"
function date_format(date) {
	let date1 = date.split("/");
	let date2 = date.split("/");
	let date3 = date.split("/");
	return date1[0] + "/" + date1[1] + "/" + date1[2] + " | " + date2[0] + "-" + date2[1] + "-" + date2[2] + " | " + date3[1] + "/" + date3[2] + "/" + date3[0];
}
```
