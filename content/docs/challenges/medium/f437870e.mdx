## الوصف

قم بكتابة دالة `function` تستقبل عدد صحيح من نوع `integer` ، تقوم الدالةـ `function` بتحويل الـعدد الصحيح `integer` المدخل إلى **عدد ثنائي ثم تقوم بحساب عدد تكرار الرقم 1** ، ** نتائج الدالة من نوع `integer`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `num = 100` | `3` |
| `num = 65` | `2` |
| `num = 888` | `6` |
| `num = 0` | `0` |

## الحل

```python tab="Python"
def count_ones(num: int) -> int:
    return bin(num)[2:].count('1')
```

```js tab="JavaScript"
function count_ones(num) {
	let binary = num.toString(2);
	let count = 0;
	for (let i = 0; i < binary.length; i++) {
		if (binary[i] == 1) {
			count++;
		}
	}
	return count;
}
```
