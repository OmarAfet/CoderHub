## الوصف

قم بكتابة  بدالة `function` تستقبل قيمة نصية من نوع `string` تقوم الـدالة  `function` **بترتيب الكلمات حسب طولها من الأقصر للأطول** وفي حال كانت هناك كلمتين بنفس الطول يكون الترتيب ابجدي ثم تقوم الدالة بإرجاع النتيجة من نوع `string`

## الحل

```python tab="Python"
def sortByLength(txt: str) -> str:
    words = txt.split()
    sorted_words = sorted(words, key=lambda x: (len(x), x))

    return ' '.join(sorted_words)
```

```js tab="JavaScript"
function sortByLength(txt) {
	const words = txt.split(" ");
	const sortedWords = words.sort((a, b) => {
		if (a.length !== b.length) {
			return a.length - b.length;
		}
		return a.localeCompare(b);
	});
	return sortedWords.join(" ");
}
```
