## الوصف

قم بكتابة  دالة `function` تستقبل قيمة نصية من نوع `string` تقوم الدالة `function` بالتحقق مما اذا كانت **توجد مسافة space في النص أم لا** في حال وجود مسافة  **استبدل كل مسافة space بعلامة #** ثم تقوم  الدالة بإرجاع النتيجة من نوع `string`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `strParam = "Riyadh"` | `"Riyadh"` |
| `strParam = "Saudi Arabia"` | `"Saudi#Arabia"` |
| `strParam = "CoderHub"` | `"CoderHub"` |
| `strParam = "What do you do?"` | `"What#do#you#do?"` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/a705e065-6874-4024-971e-8e2695b001e1/view)

## الحل

```python tab="Python"
def hasSpace(strParam: str) -> str:
    return strParam.replace(' ', '#')
```
