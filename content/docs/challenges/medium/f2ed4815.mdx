## الوصف

قم بكتابة دالة  `function` تستقبل قيمة نصية من نوع `string` تقوم الدالة  `function` **باستخراج الحرف الموجود في وسط الكلمة**  ثم قم بإرجاع الحرف من نوع `string`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `word = "test"` | `"es"` |
| `word = "z"` | `"z"` |
| `word = "salem"` | `"l"` |
| `word = "like"` | `"ik"` |

## الحل

```python tab="Python"
def middle_char(word: str) -> str:
    result = (len(word) / 2)

    if result % 1 == 0:
        result = word[int(result) - 1:int(result) + 1]
    else:
        result = word[int(result)]

    return result
```
