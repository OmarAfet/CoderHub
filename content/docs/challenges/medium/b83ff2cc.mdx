## الوصف

قم بكتابة دالة `function` تستقبل مصفوفة من نوع `double`. تقوم الدالة **بحساب الجذر التربيعي لكل عنصر في المصفوفة** ثم تقوم بإرجاع النتيجة في مصفوفة  جديدة.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `arr = [4,81,49]` | `[2,9,7]` |
| `arr = [15,6,3]` | `[3.87,2.45,1.73]` |
| `arr = [121,144,169]` | `[11,12,13]` |
| `arr = [4.2,6.9]` | `[2.05,2.63]` |

## الحل

```python tab="Python"
import math
def array_root(arr: list[float]) -> list[float]:
    result = []
    for i in arr:
        result.append(math.sqrt(i))

    return result
```
