## الوصف

تخيل أنك تعمل كمتنبئ للأحوال الجوية، حيث لديك قائمة بدرجات الحرارة اليومية. مهمتك هي تقديم معلومات لكل يوم تخبر الناس عن عدد الأيام التي يجب عليهم الانتظار فيها ليشعروا بدفء أكبر.

إذا لم يكن هناك أي يوم مستقبلي يمكن أن يكون أكثر دفئًا، يمكنك طمأنة الناس بأنهم لن ينتظروا المزيد!

لكن عليك أن تكون سريعًا وفعالًا لأن الناس يعتمدون عليك للحصول على الإجابة بسرعة.

لديك قائمة بدرجات الحرارة اليومية:

`[73, 74, 75, 71, 69, 72, 76, 73]`

- في اليوم الأول، درجة الحرارة 73، واليوم التالي درجة الحرارة 74، لذلك يحتاج الناس إلى الانتظار **يومًا واحدًا**.

- في اليوم الثاني، درجة الحرارة 74، واليوم التالي 75، لذلك يحتاج الناس إلى الانتظار **يومًا واحدًا**.

- في اليوم الثالث، درجة الحرارة 75، ويحتاج الناس إلى الانتظار **4 أيام** حتى يصلوا إلى درجة الحرارة 76.

- في اليوم الأخير، درجة الحرارة 73، ولا توجد أي أيام مستقبلية بدرجات حرارة أعلى.

الادخال :
[73, 74, 75, 71, 69, 72, 76, 73]

الاخراج :
[1, 1, 4, 2, 1, 1, 0, 0]

### **تفسير النتيجة**:

- اليوم 0: درجة الحرارة 73، نحتاج إلى **يوم واحد** للوصول إلى درجة حرارة أعلى (74).

- اليوم 1: درجة الحرارة 74، نحتاج إلى **يوم واحد** للوصول إلى درجة حرارة أعلى (75).

- اليوم 2: درجة الحرارة 75، نحتاج إلى **4 أيام** للوصول إلى درجة حرارة أعلى (76).

- اليوم 3: درجة الحرارة 71، نحتاج إلى **2 يومين** للوصول إلى درجة حرارة أعلى (72).

- اليوم 6: درجة الحرارة 76، لا يوجد أيام أعلى، لذا الإجابة **0**.

```python tab="Python"
from typing import List
def dailyTemperatures(temperatures: List[int]) -> List[int]:
    n = len(temperatures)
    result = [0] * n
    stack = []
    for i in range(n):
        while stack and temperatures[i] > temperatures[stack[-1]]:
            j = stack.pop()
            result[j] = i - j
        stack.append(i)
    return result
```
