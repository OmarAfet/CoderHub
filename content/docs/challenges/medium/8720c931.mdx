## الوصف

قم بكتابة دالة `function` تستقبل مصفوفة من نوع `string` تقوم الدالة  `function`
 *وتقوم  الدالة بإرجاع النتيجة كمصفوفة من نوع `string` بعد إضافة  الرقم 5 على كل عنصر موجود داخل المصفوفة  .
*في حال كانت المصفوفة فارغة تقوم الدالة  بارجاع المصفوفة كما هي بدون إضافة.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `arr = ["code","c"]` | `["code5","c5"]` |
| `arr = ["test","t"]` | `["test5","t5"]` |
| `arr = ["null"]` | `["null5"]` |
| `arr = ["book","pen","pencil"]` | `["book5","pen5","pencil5"]` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/8720c931-b2c0-4922-bb59-2970019a3f01/view)

## الحل

```python tab="Python"
def add_five(arr: list[str]) -> list[str]:
    return [x + '5' for x in arr]
```

```js tab="JavaScript"
function add_five(arr) {
  for (let i = 0; i < arr.length; i++) {
    arr[i] += 5;
  }
  return arr;
}
```
