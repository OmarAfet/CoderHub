## الوصف

قم بكتابة  دالة `function` تستقبل مصفوفة من نوع  `string` تقوم الدالة  `function` بحساب عدد الأحرف لكل عنصر في المصفوفة داخل مصفوفة جديدة ومن ثم تقوم الدالة  بإرجاع هذه المصفوفة.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `arr = ["Code","hub"]` | `[4,3]` |
| `arr = ["dropbox","google","page"]` | `[7,6,4]` |
| `arr = ["java","swift","javascript","python"]` | `[4,5,10,6]` |
| `arr = ["programming","languages"]` | `[11,9]` |

## الحل

```python tab="Python"
from typing import List
def word_length(arr: List[str]) -> List[int]:
    return [len(i) for i in arr]
```

```js tab="JavaScript"
function word_length(arr) {
	let arr2 = [];
	for (let i = 0; i < arr.length; i++) {
		arr2.push(arr[i].length);
	}
	return arr2;
}
```
