## الوصف

في قلب الصحراء السعودية، يقف **جبل طويق** شامخًا، رمزًا للصمود والطموح.
رحلة صعوده ليست مجرد تحدٍّ جسدي، بل هي حكاية طموح كل شاب وشابة يرون القمة هدفًا لا يُمس.
لكل يوم من الرحلة ارتفاع جديد، وأنت تريد أن تعرف: ما هو أطول عدد من الأيام التي استمر فيها الارتفاع يزداد بشكل صارم يومًا بعد يوم، بلا توقف أو تراجع؟

هذا ليس مجرد سؤال عن أرقام، بل عن الاستمرارية في الصعود رغم الصعوبات. كلما واصلت الارتفاع، زاد الطموح، لكن يوم واحد من التراجع يكسر السلسلة، ويعيدك للبداية.

**المثال الإرشادي**:
إذا كانت الارتفاعات `[1, 2, 3, 2, 3, 4, 1]`:

- من 1→2→3 (متزايد) طول=3

- ثم انكسرت عند 3→2

- بدأت سلسلة جديدة 2→3→4 (متزايد) طول=3
أطول سلسلة وجدتها هي **3 أيام** متواصلة من الزيادة، وهي تمامًا مثل عزيمتك التي لا تتوقف.

```python tab="Python"
from typing import List
def longestClimbSegment(heights: List[int]) -> int:
    if not heights:
        return 0
    max_len = 1
    curr = 1
    for i in range(1, len(heights)):
        if heights[i] > heights[i-1]:
            curr += 1
            max_len = max(max_len, curr)
        else:
            curr = 1
    return max_len
```
