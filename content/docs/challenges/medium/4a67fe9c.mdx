## الوصف

في أحد الأيام، كان **سالم**، وهو شاب سعودي يعشق التراث، يستعد لحضور **احتفال يوم التأسيس** في مدينته. أراد أن يرتدي اللباس التقليدي الخاص بمنطقته ولكنه لم يكن متأكدًا مما يجب أن يرتديه.

قرر سالم استخدام **تطبيق ذكي** يمكنه إرشاده إلى **الزي التقليدي المناسب** لكل منطقة في السعودية. قام بإدخال اسم منطقته في التطبيق، وكانت النتيجة مذهلة!
📌 **سالم يكتب في التطبيق:**

`console.log(get_saudi_traditional_outfit("الوسطى"));  `📌 **المخرجات:**

["غترة مقصب", "زبون", "بشت"]

✨ **النتيجة:**
أدرك سالم أنه يجب عليه ارتداء **غترة مقصب، زبون، وبشت**، وهو اللباس التقليدي لأهل **المنطقة الوسطى**.

ممكن انها تساعدك :
المنطقه الوسطى

غتره ، مقصب ، زبون ، بشت

المنطقة الشرقيه

غتره ، مقصب ، ثوب مرودن  ، دقله

المنطقة الغربية

طاقية ، عمامة ، ثوب ، شاية

المنطقة الجنوبية

عصابة ، بيدي ، ثوب

المنطقة الشمالية

عقال ، غتره ، بشت ، ثوب مرودن

```python tab="Python"
from typing import List

def get_saudi_traditional_outfit(region: str) -> List[str]:
    region = region.strip()
    if region == "الوسطى": return ["غترة مقصب", "زبون", "بشت"]
    if region == "الشرقية": return ["غترة مقصب", "ثوب", "مرودن", "دقلة"]
    if region == "الغربية": return ["طاقية", "عمامة", "ثوب", "شاية"]
    if region == "الجنوبية": return ["عصابة بيدي", "ثوب"]
    if region == "الشمالية": return ["عقال", "غترة", "بشت", "ثوب مرودن"]
    return []
```
