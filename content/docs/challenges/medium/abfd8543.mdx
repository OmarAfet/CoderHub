## الوصف

في هذا التحدي، يُطلب منك كتابة دالة تقوم بجمع نصين ثنائيين، وإرجاع الناتج كنص ثنائي.

- يتم تمثيل الأعداد الثنائية كسلاسل نصية تحتوي فقط على الأرقام `0` و `1`.

- الناتج يجب أن يكون نصًا ثنائيًا يمثل مجموع العددين.

- **القيود**:

- الحد الأقصى لطول كل نص هو 10410^4104.

- لا تحتوي النصوص على أصفار بادئة باستثناء النص الذي يساوي `0`.١١١١

مثال :
الادخال :
a = "11", b = "1"

الاخراج :

"100"

### **التفسير**:

- العدد الأول (`a`) يساوي `11` (3 بالعدد العشري).

- العدد الثاني (`b`) يساوي `1` (1 بالعدد العشري).

- مجموع العددين هو `100` (4 بالعدد العشري).

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `a = "11"`، `b = "1"` | `"100"` |
| `a = "1010"`، `b = "1011"` | `"10101"` |
| `a = "0"`، `b = "0"` | `"0"` |
| `a = "1"`، `b = "1"` | `"10"` |
