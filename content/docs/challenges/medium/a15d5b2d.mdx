## الوصف

في عالم مليء بالكلمات والجمل الغامضة، يكمن سرٌ في العبارات التي تبدو كما هي عند قراءتها من الأمام أو من الخلف. يُطلق عليها اسم **Palindromes**، وهي تعتبر أحجية قديمة تُختبر بها الذكاء والدقة.

مهمتك كحارس للنصوص هي أن تتحقق مما إذا كانت العبارة المدخلة تحمل هذا السحر العاكس. لكن لا تنخدع بالمساحات أو الرموز الغريبة – فقط الحروف والأرقام هي المهمة هنا. عليك تنظيف النص، قراءته بعناية، ثم إصدار الحكم: هل هو Palindrome أم لا؟

مثال :
يدخل رجل عجوز إلى مكتبتك حاملاً نصًا مكتوبًا على ورقة قديمة:

**"A man, a plan, a canal: Panama"**

يطلب منك التحقق مما إذا كانت هذه العبارة **Palindrome**. أنت تبدأ بمسح النص من الرموز الغريبة، وتحويل الأحرف إلى صغيرة، ثم تقرأ النص في الاتجاهين. في النهاية، تكتشف أن النص هو **Palindrome**.

الادخال :
"A man, a plan, a canal: Panama"

### **الخطوات**:

- **تنظيف النص**: إزالة الرموز غير الأبجدية الرقمية وتحويل النص إلى الأحرف الصغيرة:

- `"amanaplanacanalpanama"`

- **قراءة النص من الأمام والخلف**:

- `"amanaplanacanalpanama"` == `"amanaplanacanalpanama"`

الاخراج :
true

```python tab="Python"
from typing import List
def isPalindrome(s: str) -> bool:
    cleaned = ''.join(c.lower() for c in s if c.isalnum())
    return cleaned == cleaned[::-1]
```
