## الوصف

قم بكتابة دالة `function` تستقبل مصفوفة من نوع `integer` , وتقوم الـدالة `function` بترتيب عناصر المصفوفة من **الأصغر إلى الأكبر** وإرجاعها بعد عملية الترتيب

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `elements_array = [63,12,43,56,12]` | `[12,12,43,56,63]` |
| `elements_array = [88,12,23,59,1,24]` | `[1,12,23,24,59,88]` |
| `elements_array = [100,23,200,23,1]` | `[1,23,23,100,200]` |
| `elements_array = [99,88,774,2]` | `[2,88,99,774]` |

## الحل

```python tab="Python"
def sort_array(elements_array: list[int]) -> list[int]:
    return sorted(elements_array)
```
