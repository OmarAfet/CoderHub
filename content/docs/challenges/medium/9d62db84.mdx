## الوصف

قم بكتابة  دالة `function` تستقبل مصفوفة  `array` من نوع `integer `، تقوم الـدالة  `function` بإرجاع **أكثر القيم تكرارا** في المصفوفة

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `arr = [13,2,1,2,10,2,1,1,2,2]` | `2` |
| `arr = [1,2,3,4,1,5,-5,-5,-5,-5,-5,6]` | `-5` |
| `arr = [1,2,3,3,3,3]` | `3` |
| `arr = [0,5,6,2,1,5]` | `5` |

## الحل

```python tab="Python"
def most_frequent_element(arr):
    frequency_map = {}
    for digit in arr:
        if digit not in frequency_map:
            frequency_map[digit] = 0
        frequency_map[digit] += 1

    most_frequent = None
    highest_frequency = 0
    for digit, frequency in frequency_map.items():
        if frequency > highest_frequency:
            most_frequent = digit
            highest_frequency = frequency

    return most_frequent
```
