## الوصف

قم بكتابة دالة `function` تستقبل عدد عشري. تقوم الدالة **بحساب الجذر التربيعي له** وإرجاع النتيجة.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `num = 25` | `5` |
| `num = 36` | `6` |
| `num = 49` | `7` |
| `num = 64` | `8` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/50a80af2-2325-4d02-81f8-474fd73651fc/view)

## الحل

```python tab="Python"
def squareRoot(num: float) -> float:
    return num ** 0.5
```

```js tab="JavaScript"
function squareRoot(num) {
	return Math.sqrt(num);
}
```
