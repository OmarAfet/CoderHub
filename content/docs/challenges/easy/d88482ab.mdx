## الوصف

قم بكتابة دالة `function` تستقبل عددين عشريين يُمثلان نصف قطر شكل مخروطي قائم وإرتفاعه. تقوم الدالة **بحساب حجم المخروط** وإرجاع النتيجة. 

ملاحظة: قُم بتعويض الثابت `pi` بالقيمة `3.14`.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `radius = 1.3`، `height = 5.2` | `9.2` |
| `radius = 8.7`، `height = 7.8` | `617.93` |
| `radius = 3.5`، `height = 5.1` | `65.39` |
| `radius = 1`، `height = 4.2` | `4.4` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/d88482ab-9fff-41ac-b73b-cf154923fcbc/view)

## الحل

```python tab="Python"
def cone_volume(radius: float, height: float) -> float:
    return 3.14 * radius**2 * height / 3
```

```js tab="JavaScript"
function cone_volume(radius, height) {
	return (3.14 * radius * radius * height) / 3;
}
```
