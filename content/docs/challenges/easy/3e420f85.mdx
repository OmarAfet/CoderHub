## الوصف

قم بكتابة دالة `function` تستقبل عددين من نوع `integer`، ثم تقوم الدالة بإرجاع حاصل **طرح** هذين العددين.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `a = 4`، `b = 2` | `2` |
| `a = 2`، `b = -2` | `4` |
| `a = -5`، `b = 1` | `-6` |
| `a = 0`، `b = -1` | `1` |

[جرّب تحله في كودرهب](https://coderhub.tuwaiq.edu.sa/challenges/3e420f85-f4e9-4e7a-b6bc-f35a8db70cb4/view)

## الحل

```python tab="Python"
def sub(a: int, b: int) -> int:
   	return a - b
```

```js tab="JavaScript"
function sub(a, b) {
	return a - b;
}
```
