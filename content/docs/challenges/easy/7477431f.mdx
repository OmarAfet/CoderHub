## الوصف

في إحدى الليالي التراثية في **مدينة الدرعية**، اجتمع مجموعة من الأصدقاء من مختلف مناطق المملكة للاحتفال **بيوم التأسيس السعودي**. كان الحفل مليئًا بالفنون الشعبية، وكل شخص أراد أن يستعرض **لعب منطقته التقليدية**.

لكن كان هناك مشكلة... **عبدالله**، الذي ينتمي إلى المنطقة الوسطى، لم يكن متأكدًا مما إذا كانت **العرضة النجدية** هي لعبة منطقته أم لا. بينما كان صديقه **سعد** من الشمال يتحدث عن لعب **الدحة** الشهيرة، و**ناصر** من الجنوب يستعد لأداء **الخطوة الجنوبية**، لم يكن عبدالله متأكدًا!

فجأة، خطرت له فكرة! قرر استخدام **تطبيق تراثي ذكي** لمساعدته في معرفة **العب الخاص بكل منطقة**.

📌 عبدالله يسأل التطبيق:

`console.log(get_saudi_traditional_dance("الوسطى"));`📌 **الإخراج:**

"العرضة النجدية"

✨ **النتيجة:**
عبدالله تأكد أن **العرضة النجدية** هي العب الرسمي للمنطقة الوسطى، وقرر الانضمام إلى الفرقة ليؤديها بفخر! 🎺🎶

المخرج في حالة عدم التوفر :

`"لعبة غير معروفة" `
ممكن ان تساعدك /
كل منطقة ولعبها :
الوسطى (العرضة النجدية)
الشمالية (الدحة)

الجنوبية (الخطوة الجنوبيه )

الشرقية (الفجيري)

## الحل

```python tab="Python"
def get_saudi_traditional_dance(region: str) -> str:
    if region == "الوسطى":
        return "العرضة النجدية"
    
    if region == "الشمالية":
        return "الدحة"
    
    if region == "الجنوبية":
        return "الخطوة الجنوبية"
    
    if region == "الشرقية":
        return "الفجري"
        
    return "لعبة غير معروفة"
```
