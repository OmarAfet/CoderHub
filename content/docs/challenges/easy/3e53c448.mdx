## الوصف

في أحد أيام الخير التي لا تنساها المملكة، انطلقت قافلة مساعدات إنسانية يقودها **مركز الملك سلمان للإغاثة**، تعبر المدن والقرى لتصل لكل محتاج.
على متن القافلة صناديق مليئة بالأمل، كل صندوق يحمل معه علاجًا لمريض، أو سلة غذائية لعائلة تنتظر الفرج.
أمامك قائمة طويلة من الطلبات، كل طلب يخص حالة إنسانية تحتاج مبلغًا معينًا. لكن، مثل أي قافلة، هناك ميزانية محدودة عليك أن توزعها بحكمة.

هدفك ليس أن تعطي القليل للكثير، بل أن تكمل احتياجات أكبر عدد ممكن من الحالات، لأن **الجود** الحقيقي أن يرى المحتاج حاجته مكتملة، لا نصفها.
هنا يأتي دورك: عليك أن تبدأ بدعم الحالات التي تحتاج الأقل أولًا، حتى تستطيع أن تصل لعدد أكبر قبل أن تنفد الميزانية.

**المثال الإرشادي**:
إذا كان لديك الطلبات `[5, 3, 4, 2]` والميزانية `10`، ابدأ من الأصغر:

- تموّل 2 → المتبقي 8 (المموّل: 1)

- تموّل 3 → المتبقي 5 (المموّل: 2)

- تموّل 4 → المتبقي 1 (المموّل: 3)
هكذا، وصلت الفرح إلى **3 حالات** كاملة.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `needs = [5,3,4,2]`، `budget = 10` | `3` |
| `needs = [10,10,10]`، `budget = 5` | `0` |
| `needs = [1,1,1,1,1]`، `budget = 3` | `3` |
| `needs = []`، `budget = 100` | `0` |

## الحل

```python tab="Python"
from typing import List
def maxFundedCases(needs: List[int], budget: int) -> int:
    needs = sorted(needs)
    budget = budget
    
    counter = 0
    for need in needs:
        if budget >= need:
            budget -= need
            counter += 1
        else:
            return counter
    return counter
```
