## الوصف

قم بكتابة  دالة `function` تستقبل قيمة نصية من نوع `string` ، تقوم الـدالة `function` **باستخراج أول أقصى** **رقم على اليسار** ، ثم تقوم الدالة بارجاع النتيجة من نوع `integer`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `strParam = "Welcome2back"` | `2` |
| `strParam = "5"` | `5` |
| `strParam = "9753"` | `9` |
| `strParam = "nora30@gmail.com"` | `3` |

## الحل

```python tab="Python"
def left_digit(strParam: str) -> int:
    for char in strParam:
        if char.isdigit():
            return int(char)
    return None
```

```js tab="JavaScript"
function left_digit(strParam) {
  return parseInt(strParam.match(/\d/)[0]);
}
```
