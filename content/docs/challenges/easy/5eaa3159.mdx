## الوصف

قم بكتابة دالة `function` تستقبل مصفوفتين `arrays` من نوع `string` وتقوم بإرجاع قيمة `true` أو `false` اعتمادا على **مطابقة جميع الكلمات** في المصفوفة `array2` مع الكلمات الموجودة في الـمصفوفة  `array1`.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `array1 = ["hello","there","word2"]`، `array2 = ["hello","there","word2"]` | `true` |
| `array1 = ["hello","word2"]`، `array2 = ["hello","there","word2"]` | `false` |
| `array1 = ["hello","there","word2"]`، `array2 = ["hello","word2"]` | `false` |
| `array1 = ["hello","there","word2"]`، `array2 = ["word2","there","hello"]` | `true` |

## الحل

```python tab="Python"
def match_arrays(array1: list[str], array2: list[str]) -> bool:
    x = None
    y = None
    for i in array1:
        if i in array2:
            x = True
        else:
            x = False
            break

    for i in array2:
        if i in array1:
            y = True
        else:
            y = False
            break
    return x and y
```

function match_arrays(array1, array2) {
	return array1.sort().toString() == array2.sort().toString();
