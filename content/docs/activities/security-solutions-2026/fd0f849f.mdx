## الوصف

في موقع إلكتروني، يريد الفريق إجراء فحص بسيط على طول كلمات المرور.

في هذا التحدي تعتبر كلمة المرور مناسبة إذا كان طولها **8 أحرف أو أكثر**.

اكتب دالة تستقبل قائمة من كلمات المرور وتعيد عدد الكلمات المناسبة.

### مثال

`["abc", "password", "12345678"]`الناتج:

`2`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `passwords = ["abc","password","12345678"]` | `2` |
| `passwords = ["12345678"]` | `1` |
| `passwords = ["1234567"]` | `0` |
| `passwords = []` | `0` |

## الحل

```python tab="Python"
from typing import List
def count_valid_passwords(passwords: List[str]) -> int:
    return sum(1 for p in passwords if len(p) >= 8)
```

## ملاحظات

نمرّ على كلمات المرور ونعدّ كل كلمة طولها 8 أحرف أو أكثر. الشرط "أكثر من أو يساوي" لأن الطول 8 مقبول.

التعقيد: O(n) في الوقت.
