## الوصف

يحتوي ملف بيانات على مجموعة من الأرقام الموجبة والسالبة والصفر.

اكتب دالة تعيد عدد القيم التي تكون **أكبر من صفر**.

### مثال

`[-2, 5, 0, 10]`القيم الموجبة هي `5` و`10`.

الناتج:

`2`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `data = [-2,5,0,10]` | `2` |
| `data = [1,2,3]` | `3` |
| `data = [-1,-2]` | `0` |
| `data = []` | `0` |

## الحل

```python tab="Python"
from typing import List
def count_positive_values(data: List[int]) -> int:
    return sum(1 for x in data if x > 0)
```

## ملاحظات

نعدّ القيم الأكبر من صفر فقط. الصفر ليس موجبًا، فلا يدخل في العدّ.

التعقيد: O(n) في الوقت.
