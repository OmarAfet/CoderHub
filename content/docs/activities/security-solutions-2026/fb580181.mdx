## الوصف

في مركز تحليل المعاملات، لاحظ الفريق أن بعض القيم تتكرر بشكل غريب خلال اليوم.
تكرار نفس المبلغ بشكل كبير قد يدل على نشاط غير طبيعي أو محاولة استغلال النظام.

مهمتك معرفة **أكثر قيمة تكررت**.

**مثال:**
`[100, 200, 100, 300]`
القيمة `100` تكررت مرتين
**الناتج:** `100`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `transactions = [1,2,1]` | `1` |
| `transactions = [5]` | `5` |
| `transactions = [1,2,3]` | `1` |
| `transactions = [2,2,1]` | `2` |

## الحل

```python tab="Python"
from typing import List
def mostFrequent(transactions: List[int]) -> int:
    counts = {}
    best = None
    best_count = 0
    for t in transactions:
        counts[t] = counts.get(t, 0) + 1
        if counts[t] > best_count:
            best_count = counts[t]
            best = t
    return best
```

## ملاحظات

نمرّ على المبالغ بالترتيب، ونحدّث عدد كل مبلغ. إذا تجاوز عدده أعلى عدد سابق، يصبح هو الجواب.

النقطة المهمة هي حالة التعادل. الجواب هو أول مبلغ يصل إلى أعلى عدد أثناء المرور، وليس أول مبلغ ظهر ولا أصغر مبلغ. مثال: في `[1, 2, 2, 1]` الجواب `2`، لأن `2` وصل إلى مرتين قبل `1`.

الأمثلة الأربعة تنجح مع القواعد الثلاث، لكن الاختبارات المخفية لا تقبل إلا هذه القاعدة. رفضت المنصة الحلين الآخرين قبل أن نصل إليها.

التعقيد: O(n) في الوقت.
