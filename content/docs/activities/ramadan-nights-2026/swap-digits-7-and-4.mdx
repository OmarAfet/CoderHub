## الوصف

تخيل أنك تتعامل مع وظيفة بسيطة، لكنها تُستخدم كثيرًا في الأنظمة الأمنية لاختبار سلوك المدخلات. هذه الوظيفة تعتمد على نمط ثابت في **تبديل قيم معيّنة**، بينما تعيد قيمة افتراضية في الحالات الأخرى.

### المطلوب:

اكتب دالة تقوم بما يلي:

- إذا كان الرقم المدخل **4** → تُرجع **7**

- وإذا كان الرقم **7** → تُرجع **4**

- أما **في باقي الحالات، فترجع القيمة الأساسية التي يبدأ منها أي نظام قبل المعالجة، وهي ما يُعرف بـ *الحالة الصفرية***

### القيود:

لا يُسمح باستخدام:

- جملة **if**

- جملة **switch**

- المعامل الشرطي `?:`

- الدالة **eval**

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `n = 4` | `7` |
| `n = 7` | `4` |
| `n = 0` | `0` |
| `n = 5` | `0` |

## الحل

```python tab="Python"
from typing import List
def swapFourAndSeven(n: int) -> int:
    return {4: 7, 7: 4}.get(n, 0)
```
