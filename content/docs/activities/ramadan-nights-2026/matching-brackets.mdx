## الوصف

في عالم البرمجة السحري، هناك لغة قديمة تتحدث عبر الأقواس. الأقواس تأتي بثلاثة أنواع: دائرية `()`, مربعة `[]`, ومعقوفة `{}`.
ولكن هذه اللغة ليست سهلة – هناك قواعد صارمة:

- **كل قوس مفتوح يجب أن يُغلق بقوس من نفس النوع.**

- **الأقواس يجب أن تُغلق بالترتيب الصحيح.**

مهمتك كمترجم للأقواس هي التحقق مما إذا كانت الرسائل التي تصل إليك مكتوبة بشكل صحيح وفقًا لهذه القواعد. إذا نجحت في ترجمة الرسالة، ستحصل على لقب "سيد الأقواس المتطابقة".

### **المثال**:

وصلتك رسالة مكتوبة بلغة الأقواس: `"({[]})"`.
أنت تبدأ في تحليل الرسالة:

- القوس الأول مفتوح `(`.

- ثم `{` ثم `[`.

- الأقواس تُغلق بالترتيب الصحيح: `]`, `}`, `)`.
الرسالة صحيحة!

الادخال :
"(\{[]\})"

الاخراج :
true

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `s = "()"` | `true` |
| `s = "()[]{}"` | `true` |
| `s = "(]"` | `false` |
| `s = "([)]"` | `false` |

## الحل

```python tab="Python"
from typing import List
def isValid(s: str) -> bool:
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in pairs:
            if not stack or stack[-1] != pairs[c]:
                return False
            stack.pop()
        else:
            stack.append(c)
    return len(stack) == 0
```
