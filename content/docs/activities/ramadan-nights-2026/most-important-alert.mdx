## الوصف

في مركز عمليات الأمن السيبراني (SOC)، تتعامل يوميًا مع موجات من الإنذارات تأتيك من مختلف الأنظمة. بعض الإنذارات قد تكون اعتيادية، لكن نسبة صغيرة منها — غالبًا ما لا تتجاوز**اثنين** من كل مجموعة — تستحق الانتباه الفوري لأنها تتجاوز مستوى شدّة معيّن.

مهمتك هي كتابة برنامج يحسب عدد الإنذارات التي تكون درجة شدّتها **أكبر من أو تساوي** قيمة العتبة `threshold`، لتتمكن بسرعة من معرفة حجم الإنذارات الحرجة قبل اتخاذ القرار المناسب.
مثال:
alerts = [2, 5, 7, 1, 9]

threshold = 5

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `alerts = [2,5,7,1,9]`، `threshold = 5` | `3` |
| `alerts = [1,2,3]`، `threshold = 4` | `0` |
| `alerts = [4,4,4,4]`، `threshold = 4` | `4` |
| `alerts = []`، `threshold = 10` | `0` |

## الحل

```python tab="Python"
from typing import List
def countHighAlerts(alerts: List[int], threshold: int) -> int:
    return sum(1 for a in alerts if a >= threshold)
```
