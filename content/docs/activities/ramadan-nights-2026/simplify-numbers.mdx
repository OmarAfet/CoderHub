## الوصف

تخيّل أنك طاهٍ في مطبخ يُحضّر وصفة خاصة لعصير البرتقال. لديك **كسر بسيط** يمثل كمية البرتقال المطلوبة للعصير، حيث:

- البسط (a): عدد البرتقالات المطلوبة.

- المقام (b): عدد الحصص التي يجب تقسيم البرتقال عليها.

قبل أن تبدأ، طلب منك مساعدك أن **تبسّط الكسر** لأبسط صورة ممكنة. بعد التبسيط، عليك أن:

- تجمع **عدد البرتقالات المتبقية** (البسط المبسّط).

- تجمع **عدد الحصص المتبقية** (المقام المبسّط).

### **مثال :**

- المدخلات: `a = 2`، `b = 4`

- تبسيط الكسر: 24=12\frac\{2\}\{4\} = \frac\{1\}\{2\}42​=21​

- المجموع: 1+2=31 + 2 = 31+2=3

- الناتج: `3`

ثم تعطي مساعدك النتيجة النهائية وهي **مجموع البسط والمقام**.

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `a = 2`، `b = 4` | `3` |
| `a = 10`، `b = 100` | `11` |
| `a = 5`، `b = 5` | `2` |
| `a = 14`، `b = 28` | `3` |

def sumOfReducedFraction(a: int, b: int) -> int:
    from math import gcd
    g = gcd(a, b)
    return a // g + b // g
