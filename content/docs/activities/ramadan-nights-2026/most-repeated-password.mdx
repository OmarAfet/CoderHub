## الوصف

خلال تحقيق في حادثة اختراق، حصل فريق الأمن السيبراني على قائمة كلمات مرور تم تسريبها. بعض كلمات المرور تكررت عشرات المرات.
مهمتك: كتابة دالة تجد **أكثر كلمة مرور مكرّرة**. إذا كان هناك أكثر من كلمة مرور بنفس العدد الأعلى، نعيد **الأصغر ترتيبًا أبجديًا** (lexicographically).

**مثال عملي:**
`passwords = ["1234","admin","1234","root","admin","1234"]`

- "1234" تكررت 3 مرات

- "admin" تكررت مرتين

- "root" مرة واحدة

النتيجة: `"1234"`

## أمثلة

| المدخلات | المخرجات المتوقعة |
| --- | --- |
| `passwords = ["1234","admin","1234","root","admin","1234"]` | `"1234"` |
| `passwords = ["qwe","qwe","asd","asd"]` | `"asd"` |
| `passwords = ["pass","pass","word","word","test"]` | `"pass"` |
| `passwords = ["z","y","x","z","y","x"]` | `"x"` |

## الحل

```python tab="Python"
from typing import List
def mostFrequentPassword(passwords: List[str]) -> str:
    if not passwords:
        return ""
    freq = {}
    for p in passwords:
        freq[p] = freq.get(p, 0) + 1
    return sorted(freq.keys(), key=lambda x: (-freq[x], x))[0]
```
